Você é um desenvolvedor full stack responsável por evoluir o módulo de ORÇAMENTOS DE SERVIÇOS do meu sistema web de gestão financeira chamado **Lucro Líquido**.

📌 Contexto:
- O sistema já calcula orçamentos de serviços com base no MARKUP da empresa, garantindo lucratividade sobre mão de obra, custos fixos/variáveis etc.
- Agora preciso incluir, dentro do orçamento, uma seção específica para **MATERIAIS**, totalmente integrada ao cálculo final do orçamento.
- O foco é: permitir que o usuário inclua os materiais usados no serviço, com a margem de lucro desejada, e que isso some automaticamente ao valor do orçamento.

🎯 Objetivo deste ajuste:
Criar um **módulo de materiais dentro do orçamento** com:
1) Cadastro/seleção de materiais;
2) Cálculo automático de preço para o cliente (com % de acréscimo sobre o custo do fornecedor);
3) Integração total com o valor final do orçamento.

🧱 Requisitos funcionais – MATERIAIS NO ORÇAMENTO:

1. Seção “Materiais” dentro da tela de Orçamento de Serviço
- Dentro da tela de criação/edição de orçamento, crie uma seção chamada **“Materiais do Serviço”**.
- Essa seção deve funcionar como um formulário de itens de venda, permitindo adicionar vários materiais.

2. Campos por item de material (no formulário interno)
Para cada linha de material, o usuário deve poder definir/selecionar:

- **Item** (nome do material)  
- **Descrição** (campo livre para detalhes)  
- **Unid.** (unidade de medida: un, m, cx, kg, etc.)  
- **Preço de compra (fornecedor)**  
- **% acréscimo sobre o preço de compra** (ex.: 30%)  
- **Preço unitário final para o cliente** (calculado automaticamente)  
- **Quantidade**  
- **Preço total do item** (quantidade x preço unitário final)

⚙ Fórmulas importantes:
- preço_unitário_final = preço_compra_fornecedor × (1 + (percentual_acrescimo / 100))
- preço_total_item = preço_unitário_final × quantidade

3. O cliente NÃO vê o custo do fornecedor
- Na tela interna (para o usuário do sistema), ele vê:
  - Preço de compra do fornecedor
  - % acréscimo
  - Preço final
  - Total do item

- No **orçamento que vai para o cliente (PDF, impressão ou visualização)**:
  - Exibir somente: Item, Descrição, Unid., Quantidade, Preço unitário final, Preço total do item.
  - Jamais mostrar o “preço de compra do fornecedor” nem o “% de acréscimo”.

4. Botão “+” para adicionar novos materiais
- Incluir um botão “+ Adicionar material” (estilo botão mesmo, não apenas ícone), que:
  - Adiciona uma nova linha de material ao orçamento.
  - Permite tanto **escolher um material já cadastrado** quanto **cadastrar um material novo**.
E botão '-' para excluir apenas do orçaemento um item selecionado.

5. Integração com banco de dados – reuso de materiais
- Criar uma tabela de materiais em banco de dados (ex.: ), com pelo menos:
  - id_material
  - nome_item
  - descricao
  - unidade
  - preco_compra_base (último preço de compra do fornecedor, ou preço base padrão)
  - data_criacao / data_atualizacao

- Ao adicionar um material no orçamento:
  - O usuário pode **selecionar um material já cadastrado** (via campo de busca/autocomplete/dropdown) OU
  - Cadastrar um novo material na hora (que será salvo automaticamente na tabela  para uso futuro).

- Criar também uma tabela de ligação entre orçamento e materiais (ex.: ), com:
  - id_orcamento_material
  - id_orcamento
  - id_material
  - descricao_customizada (se o usuário quiser adaptar o texto para esse orçamento)
  - unidade
  - preco_compra_fornecedor
  - percentual_acrescimo
  - preco_unitario_final
  - quantidade
  - preco_total_item

6. Total de materiais e integração com o valor final do orçamento
- Na seção de materiais, mostrar no rodapé:
  - **Total de materiais** = soma de todos os  dos materiais do orçamento.

- No resumo geral do orçamento:
  - O **valor final do orçamento** deve ser:
    - total_servicos_calculado_pelo_sistema (markup, mão de obra etc.)  
    + total_materiais

- Garantir que esse total geral apareça:
  - Na tela interna de edição/visualização do orçamento.
  - No orçamento enviado/visualizado pelo cliente (PDF/HTML).

7. Experiência de uso:
- Ao começar a digitar o nome de um material, o sistema deve sugerir materiais cadastrados (autocomplete).
- Se o material ainda não existir:
  - Permitir que o usuário cadastre rapidamente (nome, unidade, preço de compra) e salve.
- Ao selecionar um material já existente:
  - Preencher automaticamente os campos padrão (nome, unidade, preço de compra base), permitindo editar o preço de compra e o % de acréscimo para aquele orçamento específico.
- Manter tudo visualmente organizado como um mini “carrinho de vendas” dentro do orçamento.
